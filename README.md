
# Mammam
🎓 Final Computer Science Thesis Project   

> 🎥 [Demo Video on Testflight](https://drive.google.com/drive/folders/1gop_1rkzeF6fJz6wyUSxx_UMsTpclI4z)<br>


### Solution Concept
“Mammam” is an iOS application that accompanies mothers in providing various complementary foods to children aged 6 months to 5 years, curated for picky eaters.


### Tech Stack
SwiftUI, Swift, SwifData, SwiftCharts, Apple Authentication, MVVM


### App Features
- Meal Planner
- Log Meal
- Summary Variation
- Story of the Day
